这些数字只表示 CPU 与本地注册表路径，不测终端写入、tmux 切换、显示器刷新率或模型延迟。不同运行之间会有噪声；不能把单项下降比例推广为所有交互的加速比例。

## 实现范围

- 50ms 轮询及动作完成时刷新版本化内存快照，绘制和移动复用快照。
- 分组、搜索投影、节点索引和帧缓存按数据、查询和尺寸失效；可变回调仍检查完整字段。
- 帮助页和不可见 Working 行不会驱动无意义重绘。
- 历史扫描使用异步目录枚举和 stat，正文仍由 Pi 公开 API 解析；冷扫描仍取决于文件数量和大小。
- 后台扫描发布时合并期间的删除、改名和退出；自定义会话目录独立缓存；读取失败保留旧缓存以便重试。

## 复现

```bash
npm run benchmark
node --experimental-strip-types scripts/benchmark.ts /path/to/baseline-checkout
```
